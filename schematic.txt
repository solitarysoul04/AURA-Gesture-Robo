=====================================================================
                          WIRING SCHEMATIC
=====================================================================

[11.1V Li-Ion Battery]
    |           |
    |           +-------------------------------+
   (+)                                         (+)
[LM2596 Buck Converter]                 [L298N Motor Driver]
(Tuned to exactly 5V)                   (11.1V Motor Power)
   (-)                                         (-)
    |                                           |
    +-------------------------------------------+---> [Common GND]

=====================================================================
                      LOGIC POWER (5V)
=====================================================================

         [5V Power]                     [Common GND]
             |                                |
             +--> VIN [RF Nano] GND <---------+
             |                                |
             +--> 5V  [ESP32-CAM] GND <-------+
             |                                |
             +--> VCC [HC-SR04] GND <---------+

=====================================================================
                      DATA & SIGNAL ROUTING
=====================================================================

[RF Nano Integrated]                      [L298N Motor Driver]
     D5  (PWM)---------------------------> ENA (Left Speed)
     D2  --------------------------------> IN1 (Left FWD)
     D3  --------------------------------> IN2 (Left REV)
     
     D10 (PWM)---------------------------> ENB (Right Speed)
     D4  --------------------------------> IN3 (Right FWD)
     D6  --------------------------------> IN4 (Right REV)

[RF Nano Integrated]                      [HC-SR04 Ultrasonic]
     A0  --------------------------------> TRIG
     A1  --------------------------------> ECHO

=====================================================================
                         MOTOR OUTPUTS
=====================================================================

[L298N Motor Driver]                      [DC Gear Motors]
     OUT1 & OUT2 ------------------------> Left Side Motors
     OUT3 & OUT4 ------------------------> Right Side Motors

=====================================================================
